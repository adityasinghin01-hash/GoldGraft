# Pinned first-reference socket package

`source/` contains the same fifteen unchanged MIT Cutover files as the existing
`legacy-php-shop/vendor/src` baseline, upstream `aedc11dde1a8793285665ca2188aff62ab5aab65`.
See `LICENSE.cutover`. This is **one unique shop**, packaged through two local
entry points; it is not a claim that a second independent shop was delivered.

Scenario/Contract/TargetPlan fixture bytes come from the GoldGraft team at
`9968f9b17327f7e424e8d202c7402b1d90c6036b`. `fixtures/socket-candidate` is a
reviewed operator-authored compatibility fixture using the team's MIT payment
library, whose licence is retained as `LICENSE.team`. It is not model output,
the durable SQLite candidate, a merchant deployment or genuine payment proof.

The accepted socket runs nine shared scenarios. The role-wide fourteen scenarios
remain registered under `../legacy-php-shop/phase1/scenarios.json`; the missing
five are not silently removed. The PHP candidate unit/browser/counterpart checks
cover additional local semantics, and real-service execution remains unqualified.

The host adapter reuses the actual team's recorder and proof components. It
admits only the reviewed fixture hashes. Unknown agent patches require qualified
protected execution and are held on this host. All three qualification flags
remain false. The executable later-domain hooks check current shared records
without fencing, migrating, deploying, restarting a merchant service or issuing
an exit certificate.
